TECH STACK USED

React.js Using React.js which is an open-source front-end JavaScript library for building interactive, role-tailored user interfaces.
Vite Using Vite for next-generation frontend tooling offering fast build bundling and instant Hot Module Replacement (HMR).
Tailwind Using Tailwind CSS as the utility-first CSS framework for structuring a clean, responsive Government of India portal theme.
Leaflet Using Leaflet GIS with Google Satellite hybrid tiles to render spatial cadastral land parcels, circle rates, and boundaries.
FastAPI FastAPI (Python) for asynchronous backend architecture because it is ideal for building scalable, high-speed RESTful APIs.
SQLModel SQLModel & SQLite (Relational ORM) to store and manage vast amounts of land parcels, projects, surveyors, and grievance tokens.
SMTP SSL Python SMTPLib (TLS 1.3) for secure, cryptographically signed legal notice email dispatch directly to landowner inboxes.
PyJWT Using PyJWT for 5-tier role authentication state and issuing 30-day single-use tamper-proof citizen objection tokens.
Web3 / SHA Web3 Escrow & SHA-256 for Direct Benefit Transfer (DBT) compensation payouts and client-side land deed verification.
